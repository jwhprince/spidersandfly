# Бесплатная публикация на Vercel

Проверено по документации Vercel 19 сентября 2026 года.

1. Войдите в Vercel и выберите бесплатный тариф **Hobby**. Для личного некоммерческого демо он подходит в пределах лимитов тарифа. [Условия Hobby](https://vercel.com/docs/plans/hobby).
2. Откройте [Vercel Drop](https://vercel.com/drop) и перетащите туда `pauki-protiv-muh.zip` из этой папки.
3. Выберите свою команду Hobby, задайте название проекта, например `pauki-protiv-muh`, и нажмите **Deploy**. После публикации Vercel выдаст ссылку на игру. [Официальная инструкция](https://vercel.com/docs/drop).

В архиве `index.html` лежит в корне вместе со стилями и скриптами. Для этой игры не нужны npm, серверная часть, база данных, переменные окружения или команда сборки. Архив также можно распаковать и открыть HTML локально.

Каждая загрузка через Drop создаёт новый проект. Для последующих обновлений с сохранением проекта подключите к нему Git-репозиторий; изменения затем публикуются через Git. [Ограничения Drop](https://vercel.com/docs/drop#limitations).

## Будет ли работать в России без VPN?

Может работать, но гарантировать доступность нельзя. В сообществе Vercel есть сообщения пользователей о частичной блокировке его IP-адресов в России. Это сообщения о конкретных проблемах, а не доказательство блокировки всех сайтов Vercel. [Пример обращения](https://community.vercel.com/t/the-ip-address-of-my-server-on-vercel-has-been-blocked-in-my-country/26076).

После публикации проверьте именно свою ссылку из РФ через домашний и мобильный интернет без VPN. Из российских сетей я её не проверял. Если доступность для этой аудитории критична, имеет смысл держать копию на другом доступном ей хостинге. Игра состоит из статических файлов, поэтому перенос простой; внешних шрифтов, CDN, API или онлайн-ресурсов внутри самой игры нет.
